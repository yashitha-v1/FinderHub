# 🔎 FinderHub — Lost & Found Mobile Application

FinderHub is a Flutter-based mobile application that helps people report, browse, and search for lost and found items. Built with Firebase, it provides authentication and cloud-based data storage to support the lost-and-found process.

## ✨ Features

- 🔐 **User Authentication** — Email/password login and signup.
- 🔑 **Google Sign-In** — Sign in using a Google account.
- 📦 **Report Lost Items** — Submit details of lost belongings.
- 🎯 **Report Found Items** — Report items found by users.
- 🏠 **Home Feed** — Browse lost and found reports.
- 🔍 **Search** — Find relevant item reports.
- 💬 **In-App Chat** — Communicate with other users.
- 👤 **User Profile** — View and manage profile information.
- 🔔 **Notifications** — Notification screen for the app.

## 🚀 Run Locally

### Prerequisites

- Flutter SDK
- Dart SDK
- Android Studio
- A Firebase project

### Setup

1. Clone the repository:

   ```bash
   git clone https://github.com/yashitha-v1/FinderHub.git
   ```

2. Open the project directory:

   ```bash
   cd FinderHub
   ```

3. Install dependencies:

   ```bash
   flutter pub get
   ```

4. Configure Firebase for your development environment.

5. Run the application:

   ```bash
   flutter run
   ```
